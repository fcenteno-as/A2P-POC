📋 Executive Summary

Goal: Investigate automatic phone number provisioning to achieve A2P 10DLC compliance and deliver an MVP recommendation with LOE estimates.

Finding: Full automation is technically feasible using Twilio's Trust Hub and A2P APIs. The recommended MVP is a two-phase approach: automated provisioning for new customers (Q3 2024) and scripted bulk migration for existing 285 customers (Q3 2024).

Estimated LOE:

  • Automated Solution (New Customers): 6-8 weeks (1 developer)
  • Bulk Migration (285 Existing): 2-3 weeks additional (1 developer)
  • Manual Provisioning (285 Existing): 20-30 weeks (1 ops person)

Recommendation: Pursue automated solution. Manual provisioning is not viable given timeline, compliance risk, and operational cost.

🎯 Background & Compliance Context

Current State

  • 285 texting customers share a single Twilio phone number (949 area code)
  • This violates A2P 10DLC regulations established by The Campaign Registry (TCR)
  • Each legal entity (Brand) must have its own registered Campaign and dedicated phone number

Compliance Violations

  1. Multiple Brands sharing one Campaign - explicitly prohibited (Twilio Error 30926)
  2. Opt-out tied to number, not employer - portability issue when employees change companies
  3. No geographic association - employees perceive as spam (949 area code unrelated to their location)

Risks of Non-Compliance

  • ⚠️ Silent message filtering already degrading deliverability (no visible errors)
  • ⚠️ Carrier blocks would affect ALL 285 customers simultaneously
  • ⚠️ Campaign registration rejection by TCR
  • ⚠️ Reduced throughput and message queuing delays
  • ⚠️ Account penalties including suspension or permanent blocking
  • ⚠️ Sender reputation damage difficult to restore

Critical: Absence of Twilio Error 30926 does NOT mean we're compliant. Enforcement is gradual and often silent.

3. ISV Architecture Review

Reviewed: A2P 10DLC Standard Brand Onboarding Guide for ISVs

Twilio offers two ISV architectures:

Option A: Secondary Customer Profiles (Sub-Accounts)

code
Master Twilio Account (AbsenceSoft)
├── Sub-Account: Customer A
│   ├── Brand SID
│   ├── Campaign SID
│   └── Phone Number(s)
├── Sub-Account: Customer B
│   ├── Brand SID
│   ├── Campaign SID
│   └── Phone Number(s)

Pros:

  • Complete isolation of customer data
  • Billing can be separated per customer
  • Stronger security boundaries

Cons:

  • Each sub-account needs separate authentication
  • More complex to manage (285+ accounts)
  • Harder to aggregate metrics/monitoring
  • Requires significant refactoring of existing TextProvider code

Option B: Single Account with Messaging Service Number Pool (RECOMMENDED)

code
Master Twilio Account (AbsenceSoft)
└── Messaging Service: "AbsenceSoft core application SMS messaging"
    ├── Number Pool (285+ phone numbers)
    │   ├── +1-949-XXX-XXXX → Brand A → Campaign A
    │   ├── +1-212-XXX-XXXX → Brand B → Campaign B
    │   └── +1-512-XXX-XXXX → Brand C → Campaign C
    ├── Shared webhook endpoints
    └── Shared opt-out/help keywords

Pros:

  • ✅ Centralized management (one Messaging Service)
  • ✅ Shared settings (webhooks, callbacks, opt-out)
  • ✅ Minimal code changes (specify FROM number per customer)
  • ✅ Scalable (add numbers to pool easily)
  • ✅ Recommended by Twilio for ISVs
  • ✅ Compliant (each Brand/Campaign/Number properly registered)

Cons:

  • Must track which number belongs to which customer
  • Inbound routing requires mapping To number → customer

RECOMMENDATION: Option B - Single Messaging Service with Number Pool

Rationale: Simpler, more maintainable, scales better, and aligns with existing AbsenceSoft architecture.

namespace AbsenceSoft.Logic.Twilio
{
    public interface ITwilioProvisioningService
    {
        Task<BrandRegistrationResult> RegisterBrandAsync(Customer customer);
        Task<BrandStatus> GetBrandStatusAsync(string brandSid);
        Task<CampaignRegistrationResult> RegisterCampaignAsync(string brandSid, CampaignData campaignData);

    public class TwilioProvisioningService : ITwilioProvisioningService, IDisposable
    {
        private readonly ILogger _logger;
        private readonly IConfigService _configService;
        private readonly string _accountSid;
        private readonly string _authToken;
        private readonly string _messagingServiceSid;
        private readonly HttpClient _httpClient;
        private readonly string _brandPolicySid;

        public TwilioProvisioningService(
            ILogger logger,
            IConfigService configService)
        {
            _logger = logger;
            _configService = configService;
            _accountSid = _configService.AppSetting(Settings.TextProvider.AccountSid);
            _authToken = _configService.AppSetting(Settings.TextProvider.AuthToken);
            _messagingServiceSid = _configService.AppSetting(Settings.TextProvider.MessagingServiceSid);
            _brandPolicySid = _configService.AppSetting(Settings.TextProvider.BrandPolicySid);

            TwilioClient.Init(_accountSid, _authToken);

            _httpClient = new HttpClient
            {
                BaseAddress = new Uri("https://trusthub.twilio.com")
            };
            _httpClient.DefaultRequestHeaders.Authorization =
                new System.Net.Http.Headers.AuthenticationHeaderValue(
                    "Basic",
                    Convert.ToBase64String(Encoding.ASCII.GetBytes($"{_accountSid}:{_authToken}"))
                );
        }

        public async Task<TextProfile> ProvisionCompletePhoneNumberAsync(
            Customer customer,
            string preferredState = null,
            string preferredAreaCode = null)
        {
            using (new InstrumentationContext("TwilioProvisioningService.ProvisionCompletePhoneNumberAsync"))
            {
                var textProfile = new TextProfile
                {
                    CustomerId = customer.Id,
                    AccountSid = _accountSid,
                    AuthToken = _authToken,
                    MessagingServiceSid = _messagingServiceSid,
                    Status = A2PComplianceStatus.NotStarted,
                    PreferredState = preferredState ?? customer.Contact?.State,
                    PreferredAreaCode = preferredAreaCode
                };

                try
                {
                    // Step 1: Register Brand
                    _logger.LogInformation(
                        "Starting Brand registration for customer {CustomerId}",
                        customer.Id
                    );

                    var brandResult = await RegisterBrandAsync(customer);
                    textProfile.BrandSid = brandResult.BrandSid;
                    textProfile.Status = A2PComplianceStatus.BrandPending;
                    textProfile.BrandData = brandResult.BrandData;
                    textProfile.Save();

                    DataDogMetrics.Increment("absencesoft.phone.provisioning.brand.submitted");

                    // Step 2: Register Campaign
                    _logger.LogInformation(
                        "Starting Campaign registration for customer {CustomerId}, Brand {BrandSid}",
                        customer.Id,
                        brandResult.BrandSid
                    );

                    var campaignData = new CampaignData
                    {
                        UseCase = "CUSTOMER_CARE",
                        Description = "Employee absence and leave management notifications",
                        SampleMessages = new List<string>
                        {
                            $"Welcome to {customer.Name} absence notifications powered by AbsenceSoft. Reply STOP to opt out.",
                            "Your leave request has been approved. Contact your HR manager if you have questions.",
                            "Reminder: Submit your leave paperwork by 5 PM today."
                        },
                        OptInWorkflow = "Employee opts in when registered in system",
                        OptOutWorkflow = "Reply STOP to opt out at any time"
                    };

                    var campaignResult = await RegisterCampaignAsync(brandResult.BrandSid, campaignData);
                    textProfile.CampaignSid = campaignResult.CampaignSid;
                    textProfile.Status = A2PComplianceStatus.CampaignPending;
                    textProfile.CampaignData = campaignResult.CampaignData;
                    textProfile.Save();

                    DataDogMetrics.Increment("absencesoft.phone.provisioning.campaign.submitted");

                    // Step 3: Search and Purchase Phone Number
                    _logger.LogInformation(
                        "Searching for available phone number for customer {CustomerId}",
                        customer.Id
                    );

                    var searchResult = await SearchAvailableNumbersAsync(
                        textProfile.PreferredState,
                        textProfile.PreferredAreaCode
                    );

                    if (!searchResult.AvailableNumbers.Any())
                    {
                        throw new Exception(
                            $"No available phone numbers found for state {textProfile.PreferredState} " +
                            $"and area code {textProfile.PreferredAreaCode}"
                        );
                    }

                    var selectedNumber = searchResult.AvailableNumbers.First();
                    var purchasedNumber = await PurchasePhoneNumberAsync(selectedNumber.PhoneNumber);

                    textProfile.TextNumber = purchasedNumber.PhoneNumber;
                    textProfile.PhoneNumberSid = purchasedNumber.Sid;
                    textProfile.Save();

                    DataDogMetrics.Increment("absencesoft.phone.provisioning.number.purchased");

                    // Step 4: Add to Messaging Service
                    _logger.LogInformation(
                        "Adding phone number {PhoneNumber} to Messaging Service for customer {CustomerId}",
                        purchasedNumber.PhoneNumber,
                        customer.Id
                    );

                    await AddNumberToMessagingServiceAsync(
                        purchasedNumber.Sid,
                        _messagingServiceSid
                    );

                    // Step 5: Associate with Campaign
                    _logger.LogInformation(
                        "Associating phone number {PhoneNumber} with Campaign {CampaignSid}",
                        purchasedNumber.PhoneNumber,
                        campaignResult.CampaignSid
                    );

                    await AssociateNumberWithCampaignAsync(
                        purchasedNumber.Sid,
                        campaignResult.CampaignSid
                    );

                    textProfile.ProvisionedOn = DateTime.UtcNow;
                    textProfile.Save();

                    DataDogMetrics.Increment("absencesoft.phone.provisioning.success");

                    _logger.LogInformation(
                        "Phone provisioning completed successfully for customer {CustomerId}. " +
                        "Brand: {BrandSid}, Campaign: {CampaignSid}, Number: {PhoneNumber}",
                        customer.Id,
                        brandResult.BrandSid,
                        campaignResult.CampaignSid,
                        purchasedNumber.PhoneNumber
                    );

                    return textProfile;
                }
                catch (Exception ex)
                {
                    textProfile.Status = A2PComplianceStatus.Failed;
                    textProfile.StatusReason = ex.Message;
                    textProfile.Save();

                    DataDogMetrics.Increment("absencesoft.phone.provisioning.failure");

                    _logger.LogError(
                        ex,
                        "Phone provisioning failed for customer {CustomerId}",
                        customer.Id
                    );

                    throw;
                }
            }
        }

        public async Task<BrandRegistrationResult> RegisterBrandAsync(Customer customer)
        {
            using (new InstrumentationContext("TwilioProvisioningService.RegisterBrandAsync"))
            {
                try
                {
                    // Step 1: Create TrustProduct (Brand Profile)
                    var trustProductRequest = new
                    {
                        friendly_name = $"{customer.Name} - A2P Brand",
                        email = customer.Contact?.Email ?? "support@absencesoft.com",
                        policy_sid = _brandPolicySid,
                        status_callback = _configService.AppSetting(Settings.TextProvider.BrandStatusCallback)
                    };

                    var trustProductResponse = await _httpClient.PostAsync(
                        "/v1/TrustProducts",
                        new StringContent(
                            JsonConvert.SerializeObject(trustProductRequest),
                            Encoding.UTF8,
                            "application/json"
                        )
                    );

                    trustProductResponse.EnsureSuccessStatusCode();
                    var trustProductJson = await trustProductResponse.Content.ReadAsStringAsync();
                    var trustProduct = JsonConvert.DeserializeObject<dynamic>(trustProductJson);
                    string trustProductSid = trustProduct.sid;

                    _logger.LogInformation(
                        "Created TrustProduct {TrustProductSid} for customer {CustomerId}",
                        trustProductSid,
                        customer.Id
                    );

                    // Step 2: Create EndUser (Business Entity)
                    var ein = await DecryptEIN(customer.TaxId); // Decrypt EIN

                    var endUserRequest = new
                    {
                        friendly_name = customer.Name,
                        type = "business",
                        attributes = new
                        {
                            business_name = customer.Name,
                            business_registration_number = ein,
                            business_type = "private_profit",
                            business_industry = "HUMAN_RESOURCES",
                            business_address = customer.Contact?.Address,
                            business_address_city = customer.Contact?.City,
                            business_address_subdivision = customer.Contact?.State,
                            business_address_postal_code = customer.Contact?.PostalCode,
                            business_address_country = "US",
                            business_phone_number = customer.Contact?.Phone ?? "+18005551234",
                            email = customer.Contact?.Email ?? "support@absencesoft.com",
                            website = $"https://absencesoft.com/customers/{customer.Id}"
                        }
                    };

                    var endUserResponse = await _httpClient.PostAsync(
                        "/v1/EndUsers",
                        new StringContent(
                            JsonConvert.SerializeObject(endUserRequest),
                            Encoding.UTF8,
                            "application/json"
                        )

        public async Task<MigrationReport> MigrateExistingCustomersAsync(
            List<string> customerIds = null,
            int batchSize = 10,
            bool dryRun = false)
        {
            var report = new MigrationReport
            {
                StartedAt = DateTime.UtcNow,
                DryRun = dryRun
            };

            try
            {
                // Get customers to migrate
                var customersToMigrate = customerIds ?? GetCustomersWithSharedNumber();
                report.TotalCustomers = customersToMigrate.Count;

                _logger.LogInformation(
                    "Starting phone migration for {Count} customers. DryRun: {DryRun}, BatchSize: {BatchSize}",
                    customersToMigrate.Count,
                    dryRun,
                    batchSize
                );

                // Process in batches
                var batches = customersToMigrate
                    .Select((id, index) => new { id, index })
                    .GroupBy(x => x.index / batchSize)
                    .Select(g => g.Select(x => x.id).ToList())
                    .ToList();

                for (int i = 0; i < batches.Count; i++)
                {
                    var batch = batches[i];
                    _logger.LogInformation(
                        "Processing batch {BatchNumber} of {TotalBatches} ({Count} customers)",
                        i + 1,
                        batches.Count,
                        batch.Count
                    );

                    // Process batch in parallel
                    var tasks = batch.Select(customerId =>
                        MigrateCustomerAsync(customerId, dryRun, report)
                    );

                    await Task.WhenAll(tasks);

                    // Rate limiting - wait between batches
                    if (i < batches.Count - 1)
                    {
                        _logger.LogInformation("Waiting 5 seconds before next batch (rate limiting)...");
                        await Task.Delay(TimeSpan.FromSeconds(5));
                    }
                }

                report.CompletedAt = DateTime.UtcNow;
                report.Duration = report.CompletedAt.Value - report.StartedAt;

                _logger.LogInformation(
                    "Migration completed. Total: {Total}, Success: {Success}, Failed: {Failed}, Skipped: {Skipped}",
                    report.TotalCustomers,
                    report.Successes.Count,
                    report.Failures.Count,
                    report.Skipped.Count
                );

                // Generate Excel report
                var reportPath = GenerateExcelReport(report);
                _logger.LogInformation("Excel report generated at: {ReportPath}", reportPath);

                return report;
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Fatal error during migration");
                report.FatalError = ex.Message;
                throw;
            }

        private async Task MigrateCustomerAsync(
            string customerId,
            bool dryRun,
            MigrationReport report)
        {
            try
            {
                var customer = Customer.GetById(customerId);
                if (customer == null)
                {
                    report.AddSkipped(customerId, "Customer not found");
                    return;
                }

                var existingProfile = GetCustomerTextProfile(customerId);
                if (existingProfile == null)
                {
                    report.AddSkipped(customerId, "No TextProfile found");
                    return;
                }

                if (IsAlreadyMigrated(existingProfile))
                {
                    report.AddSkipped(customerId, "Already has dedicated number");
                    return;
                }

                if (dryRun)
                {
                    report.AddDryRun(customerId, customer.Name, customer.Contact?.State);
                    _logger.LogInformation(
                        "[DRY RUN] Would migrate customer {CustomerId} ({CustomerName})",
                        customerId,
                        customer.Name
                    );
                    return;
                }

                _logger.LogInformation(
                    "Migrating customer {CustomerId} ({CustomerName})...",
                    customerId,
                    customer.Name
                );

                // Perform full provisioning
                var newProfile = await _provisioningService.ProvisionCompletePhoneNumberAsync(
                    customer,
                    customer.Contact?.State,
                    null
                );

                // Save new profile
                newProfile.CustomerId = customerId;
                newProfile.EmployerId = existingProfile.EmployerId;
                newProfile.Save();

                // Mark old profile as migrated (don't delete yet - keep for 30 days)
                existingProfile.StatusReason = $"Migrated to {newProfile.Id} on {DateTime.UtcNow}";
                existingProfile.Status = A2PComplianceStatus.Suspended;
                existingProfile.Save();

                report.AddSuccess(customerId, customer.Name, newProfile.TextNumber, newProfile.BrandSid, newProfile.CampaignSid);

                _logger.LogInformation(
                    "Successfully migrated customer {CustomerId} to number {PhoneNumber}",
                    customerId,
                    newProfile.TextNumber
                );
            }
            catch (Exception ex)
            {
                report.AddFailure(customerId, ex.Message);
                _logger.LogError(
                    ex,
                    "Failed to migrate customer {CustomerId}",
                    customerId
                );
            }
        }

                {
                    _logger.LogInformation(

                        customerId

                }

                try
                {
                    var customer = Customer.GetById(customerId);
                    if (customer == null)
                    {
                        throw new ArgumentException($"Customer {customerId} not found\");
                    }

                    _logger.LogInformation(
                        \"Starting auto-provisioning for customer {CustomerId}\",
                        customerId
                    );

                    // Use provisioning service
                    using (var provisioningService = new TwilioProvisioningService(_logger, ConfigService))
                    {
                        var textProfile = await provisioningService.ProvisionCompletePhoneNumberAsync(
                            customer,
                            customer.Contact?.State,
                            null  // area code - will use state if not provided
                        );

                        textProfile.CustomerId = customerId;
                        textProfile.EmployerId = employerId;
                        textProfile.Save();

                        _logger.LogInformation(
                            \"Successfully auto-provisioned phone number for customer {CustomerId}: {PhoneNumber}\",
                            customerId,
                            textProfile.TextNumber
                        );

                        return textProfile;
                    }
                }
                catch (Exception ex)
                {
                    _logger.LogError(
                        ex,
                        \"Failed to auto-provision phone number for customer {CustomerId}. Falling back to legacy method.\",
                        customerId
                    );

                    // Fall back to legacy method on failure
                    return CreateTextProfileLegacy(customerId, employerId);
